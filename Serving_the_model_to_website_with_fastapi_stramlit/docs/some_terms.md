# * POST Method

* POST is an HTTP method used to send data from the client side (browser, mobile app, or any application) to the server.

* POST is mainly used when we want to create, submit, save, or process some information on the server.

* When a user enters information on a website and submits it, the data is sent to the server using the POST method.

Example:

* When a user creates a new account on a website, they enter their name, email, and password. This information is sent to the server using POST, and the server saves the new user account.

* When a user uploads a profile picture, the image data is sent to the server using POST, and the server stores that image.

* When a user sends a message in a chat application, the message is sent through POST and saved on the server.

# * Why do we use POST?

* To create new data

* To send user information securely

* To submit forms

* To upload files

* To save information in a database

* To perform actions that change data on the server

# * How POST works

* User enters data on the website.

* The website sends that data to the server using a POST request.

* The server receives the data.

* The server processes or stores the information.

* The server sends a response back to the user.

# * Simple Difference

GET means we want to receive or read information from the server.

POST means we want to send information to the server to create or process something.

# * Simple Memory Trick

GET = Give me data

POST = Take my data and save/process it
